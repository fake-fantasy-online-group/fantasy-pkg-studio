# Fake Fantasy Editor

独立桌面资源编辑器：左侧文件树，右侧标签页与内容，操作通过原生菜单、快捷键和右键菜单完成。

编辑器使用原生文本控件，无 Monaco、Theia 或前端框架依赖。桌面外壳复用 Electron，因此仍包含 Chromium 运行时；“轻量”不代表原生 WebView 级别的安装包体积。

## 安装、启动与打包

需要 Node.js 22+。在需要实际运行时执行：

```sh
npm ci
npm start
npm run package:app
```

桌面产物输出到 `dist/`，使用当前平台打包。不同平台需分别运行验证，不自动发布。
保留已有 VS Code 插件打包入口 `npm run package:plugin`，独立应用不依赖安装该插件。

## 工程与使用

一个 PKG 对应一个独立目录：

```text
my-resources.pkg-project/
  pkg-studio.json          # 版本化工程元信息、条目路径和导出基线
  resources/              # 实际编辑和预览的资源文件
  .pkg-studio/source.pkg   # 保留未知字段和未修改存储字节的原包副本
```

1. “从 PKG 新建工程”选择原包和一个尚不存在的工程目录。全量导出成功后才发布工程；取消或失败不会切走已打开的工程。
2. 以后用“打开工程”重开目录，无需再次导出。工程可整体移动，不要单独删除元信息或原包副本。
3. 左侧选择文件，在右侧编辑 UTF-8 文本或查看资源预览。文本编辑上限为 2 MiB，保留 BOM 与统一换行；其他编码和混合换行保持只读。
4. “保存文本”直接写入 `resources/`。切换文件保留未保存草稿，关闭只对未保存草稿提示；已保存工程文件不会丢失。
5. 可以用外部工具编辑 `resources/`，回到应用刷新工程。保存前会比较读取时的内容校验值；检测到冲突时保留草稿，需先复制草稿或明确重新载入磁盘内容。
6. 原始文件／目录导入和 PNG 转换导入也写入工程资源。“恢复原包内容”会撤销对应工程资源修改。
7. “导出 PKG”先保存草稿，再扫描工程文件，只有相对导出基线发生变化的条目重新编码。生成新包，不覆盖原包或工程内部文件。

当前保留原始条目集合，不支持新增、删除、重命名条目。缺失资源会导致重新打包失败；未登记文件不进入输出包。工程元信息的版本、路径映射及原包副本会校验；不要手动修改这些内部文件。

首次导出沿用单条目 64 MiB 上限；超过上限、路径不安全或文件名碰撞会整体失败，不生成可用的半成品工程。大型资源包需要额外磁盘空间来保存原包副本和解包内容。

## 预览与格式边界

- 文件树、标签页和面包屑使用本地 SVG 类型图标。`.link`、`.npc`、`.lst` 与 `.def/.ini/.txt/.cfg` 支持严格 UTF-8/GBK 文本预览；带 BOM 的 UTF-16 文本也可只读查看。编码不合法时保留原始字节，不强行替换字符。
- `.prc` 支持 QQF PROC 版本 65537、头部大小 16 的触发区预览，每页 50 条，显示区域轮廓、区域编号与顶点坐标；不解释尾部未知数据。输入上限 32 MiB。
- 地图 `.link/.npc/.lst` 默认显示每页 50 条的游戏配置表：传送目标与落点、静态 NPC 名称与脚本及商店编号、怪物刷新点与朝向。关联名称从当前工程的地图定义和怪物表读取，缺失时保留编号；资源链接仅在工程内唯一匹配时可用。右键可切换源文本，未保存的草稿须先保存再预览。

- 定长记录 BIN 提供“数据查看”和“表定义”两种视图，支持行与列分页。已登记表优先使用原服务端 `ovplan.json` / `ovrepeat.json`，校验表版本和记录长度，沿用其整数类型、GBK 文本与重复字段规则。其他表读取工程资源中的 `ov_res.bin`；缺少时可通过“资源 → 关联表定义…”选择外部文件，副本随工程保存。不会从其他工程自动借用定义。可用“取消外部表定义关联”移除副本。
- 只有匹配表名、记录长度和字段边界的定义用于解码；缺少、不匹配或损坏的定义保留按记录分行的原始字节列，定义视图显示具体状态。特殊 BIN 仍可按 4096 字节分页查看原始十六进制及 ASCII 对照。其他未支持专用格式显示原始数据摘要。
- GSA 按客户端图块记录顺序拼接各帧，支持逐帧查看与播放；格式没有方向字段，按单方向帧序列展示。预览速度不代表游戏时序。可编辑 PNG 导出/导入仍仅处理首个图块；导入必须保持尺寸，像素值须能由原格式精确表示。
- 独立应用的 GSN/GSO（DIMG）预览支持方向选择、逐帧查看和播放，保持统一画布与帧偏移；FPS 仅控制预览速度，不代表游戏时序。不支持的像素编码或异常数据会明确提示。
- MIDI 提供音符分布图：横轴为原始 tick，纵轴为 MIDI 音高，颜色区分通道。只显示音符事件，不合成声音、不模拟踏板；格式 2 的独立序列按各自起点叠加。解析依据 [Standard MIDI Files](https://midi.org/standard-midi-files-specification)，预览最多 256 轨、500000 事件、30000 音符。
- GSM 使用场景预览：旧式地图读取 DAT 地形库，现代 PMIT 地面依据四角地形编号与 TIL 形状合成首帧；已确认的普通静态库物件独立叠加。支持拖动、缩放、适应画布和按需图层菜单，切回标签页保留视角与图层开关。图像最大边长 2048，不等于游戏原分辨率渲染。
- GSM 物件区按客户端版本与标志顺序读取：前置数据、Cover、内嵌固定物件、短字段、附加记录，再到地面装饰与库物件表。已知但尚未绘制的数据块按结构校验长度后跳过，不再因为存在这些标志而拒绝整个物件区；截断或异常计数会停止物件解析并保留地面。Cover、固定物件和 FieldColor 仍不参与绘制。
- 同名 PRC/LINK、NPC、LST、MSK 分别提供传送/触发区域、NPC、怪物刷新点和阻挡图层；只在地面存在已确认的游戏坐标映射时叠加。传送名称和目标路径沿用 MapDef/MapSourceName，怪物名称来自当前工程的 `ov_cmon.bin` 原始字段计划；缺少关联表时保留编号，不猜名称或形象。
- 点击场景物件或逻辑标记，按需查看游戏信息并跳转当前工程中的资源。路径重名不选择猜测结果，缺失资源明确标出；场景问题在紧凑入口中展开。物件子目录查找沿用客户端唯一后缀匹配规则。未恢复的 Cover、内嵌固定物件、动画与完整遮挡顺序不宣称已还原。
- 场景依赖只从当前工程读取，单资源上限 64 MiB、每次最多 256 个不同依赖名、总读取量 128 MiB；预览前后检查文件指纹，避免混用外部修改前后的内容。界面只保存视图状态，不持久缓存场景素材。超限、损坏和缺失分别提示，编码网格回退不作为完整场景。
- `tileimg*.dat` 按 64 图块分页；`terrashp*.dat` 按 64 地形分页展示变体与四帧图块编号。MSK 显示通行／阻挡格，SMP 解码小地图采样图。输出图片最大边长 2048，必要时缩小。
- `.mask` 显示物件足迹坐标（含空足迹），与 `.msk` 的通行网格区分；flag 保留原值，不宣称已经恢复原生遮挡规则。`.til` 按客户端每组四项取首项的规则显示15种地面形状，动画资源按真实帧分页。`.tga` 按像素格式与原点方向还原图片，其具体游戏用途尚未确认。
- `ov_res.bin` 自身显示 UDg 结构、字段、类型码、偏移和长度。RAR4 显示分页目录，不解包或执行内容；已发现的 `JZP.rar` 成员在同包外层存在对应资源，未发现游戏递归加载 RAR 的链路。
- `.glg`、`.krd` 和 `ov_avatarres.bin` 尚未找到可靠的实际读取实现，保持未解析；原始字节查看不等于格式预览支持。无后缀 DIMG 按签名预览，不推断其运行时用途。
- `.eff` 提供独立特效合成预览，按客户端的关键帧、位置样条、素材帧间隔和透明／叠加／最大值混合规则绘制，支持播放、暂停、拖动进度与重播。素材仅从当前工程的 `magic/magic/magicNNNN.gso` 读取，取默认首方向；不模拟角色跟随、目标移动或朝向切换。姿态按 30 Hz 采样，预览一轮不推断游戏循环模式。右键保留结构查看和源文本入口。
- EFF 合成最多处理 64 层、每素材 128 张非空帧、累计 16M 解码像素及 32 MiB PNG；超过 60 秒不生成截断播放轨迹。缺失素材、超限和未支持引用会明确标示不完整预览。`.eff_` 尚无运行时消费证据，保留文本查看。
- GSN/GSO 的 3D 转换支持下述受支持 DIMG 编码回写；普通 PNG 导入仍仅用于 GSA。地图、地形库仍可原格式导出、替换。不能把 PNG 改扩展名当作转换。
- 预览/原始导出的单条目读取上限与索引上限均为 64 MiB；同尺寸大文件不能通过目录比较，可用单文件替换。
- 重打包分块复制未修改条目，保留其存储字节、索引未知字段和原始名字节。当前支持替换，不新增、删除或重命名条目。
- 输出限制在 32 位偏移范围内，原子发布需要输出文件系统支持硬链接；不支持时可先保存到本机磁盘。
- 包覆盖优先级仍由客户端挂载顺序决定；应用不自动部署资源或修改客户端清单。

## 3D 模型转二维素材

通过原生“3D”菜单打开转换窗口，或对 GSN/GSO 资源右键选择“用 3D 模型替换…”。无需打开 PKG 工程也可转换并导出独立素材。转换引擎使用本机 Blender 4.2 或更新版本；应用不内置或自动安装 Blender。macOS/Linux 常见安装位置会自动查找，其他位置通过“3D → 选择 Blender…”指定，选择会保存到应用用户配置。

- 输入格式：GLB、glTF、FBX、OBJ、BLEND、STL、PLY。模型的外部贴图、glTF 缓冲区和 OBJ 材质文件须保留在原相对位置。缺失贴图会报错。导入器是否支持具体文件版本、材质和动画取决于所选 Blender；不是跨平台或全格式验收声明。
- 编辑范围：模型旋转与缩放、动画选择及帧区间、相机方位与俯视角、正交视野、像素偏移、灯光强度，以及逻辑画布、1×/2×/4×、方向数与每方向帧数。模型编辑参数保留在当前队列中，导出时随 `conversion.json` 保存。
- “读取动画列表”按需读取源模型。默认使用源场景当前动画；复杂多对象/NLA 动画无法安全指定单个动作时会明确拒绝，可在 Blender 工作副本中整理时间线。静态格式不会凭空生成动作。
- “在 Blender 中编辑工作副本…”另存一个新 `.blend` 文件并打开 Blender，供顶点建模、材质、骨骼等深度编辑。原始输入不覆盖，完成编辑后保存工作副本并在队列中选择该副本重新转换。
- “预览当前帧”只渲染所选帧；“转换当前模型”生成完整方向序列。五方向采用当前人物客户端的存储槽顺序 `[0, 1, 2, 3, 7]`，对应 45° 八方向槽位；其他方向数均匀采样。相机零方位从世界 +Y 看向原点，可调整方位角对齐不同模型的正面。不要把这个顺序视为所有资源的通用约定。
- 每个模型有独立参数和目标映射。批量转换按队列依次执行，可取消；已经完成的结果保留，每项失败单独显示。“将当前参数应用到全部模型”复制参数并使旧结果失效，不自动猜测资源映射。
- 导出结果包含透明 PNG 序列、真正编码的 DIMG `sprite.gsn` 和参数清单，写入所选目录下的新子目录，不覆盖已有产物。新建独立素材不包含装备挂点，不能自动加入 PKG 条目集合；需要在工程中显式映射到已有条目才能写入、重打包。
- 映射到现有资源后，帧数、方向数和逐帧裁切尺寸由目标确定；倍率仍可选。编码支持 DIMG 1.1–1.5 的已解析记录布局，保留未知字段、全局表、挂点、标志和尾部字节；IANI、附加像素平面、不能精确换算到所选倍率的尺寸会拒绝。角色身体与装备部件可选择各自的锚点规则。
- 保留挂点不等于自动让新模型的手、头和武器与旧动作匹配。替换身体/部件需制作对应动作并预览对齐；本功能不自动生成骨骼、装备挂点或遮挡表。转换生成的像素也不会修改游戏控制动作时序的配置。
- 完整转换后，显式选择“写入当前映射资源”或批量写入。写入比较转换时的工程路径及目标内容哈希；外部修改会拒绝覆盖。批量写入为逐项原子写入，可能部分成功，会逐项报告；不宣称跨文件事务。之后通过主窗口“导出 PKG”另存新包。
- 每个会话最多 64 个输入，单模型文件上限 512 MiB，单转换像素预算 63 MiB，单个编码资源/PNG 序列各上限 64 MiB，会话结果缓存上限 512 MiB。任务在后台运行，单模型超时 20 分钟；临时产物退出时清理。较大的资源请降低倍率/尺寸/帧数，或拆分动作。

Blender 通过参数数组启动，禁用文件自动脚本执行；不会执行模型携带的 Python 脚本。应用关闭前需取消或等转换任务完成。只做本地转换及工程写入，不自动发布资源。

## 游戏资源的消费关系

地图由一组资源构成：GSM 提供地面和物件布局，TIL 或地形 DAT 提供地面图块，MSK 用于移动限制，SMP 用于小地图。PRC 给出触发区域，LINK 关联传送目标；NPC 配置交互角色，LST 配置怪物刷新点。场景预览组合已确认的图层，尚未复现完整游戏渲染。

格式实现参考客户端的 `ReferenceFirstWorldWindowOwner`、`FloorRenderer`、`PlayerController.Mask`、`MapLink.Legacy`、`MapNpc`、`ReferenceFirstWorldMinimapHud`，以及服务端 `server/internal/data/mapfiles.go` 的实际调用链。客户端 `ResLoader` 存在补丁包覆盖及回退顺序；编辑器只使用当前工程的资源，不自动从其他包取同名依赖。

EFF 是多层特效模板，`EffectPlayer` 解析关键帧时间、位置、缩放、旋转、颜色与透明度。已确认的 `magicNN` 引用通过 `EffectPlayer.MagicFrames` 加载 `magic/magic/magicNNNN.gso`，再由 `EffectPlayer.Update` 更新姿态与生命周期；未知引用不推断路径。

## 源码

- `src/main.cjs`、`src/preload.cjs`：独立窗口、系统对话框与隔离桥接。
- `src/app.js`、`src/index.html`、`src/style.css`：文件树、标签页、快速打开与原生文本编辑器。
- `src/project.cjs`：工程创建、元信息与资源持久化。
- `src/worker.cjs`：后台读取、工程保存、导入导出与重打包。
- `src/pkg.cjs`、`src/preview.cjs`、`src/dimg.cjs`：共享格式核心。
- `src/map-preview.cjs`、`src/midi-preview.cjs`：桌面地图／地形与 MIDI 只读预览。
- `src/map-scene.cjs`、`src/map-logic.cjs`、`src/scene-contract.cjs`：场景地面与物件合成、游戏逻辑读取及统一坐标变换。
- `src/binary-preview.cjs`：未知 `.bin` 的原始字节分页查看，不解析专用表结构。
- `src/table-preview.cjs`、`src/ovplan-preview.cjs`：定长 BIN 记录、原加载计划与外部表定义匹配、字段解码和有界表格分页。
- `src/raster-preview.cjs`、`src/structured-preview.cjs`、`src/archive-preview.cjs`：物件足迹、TIL/TGA 像素、UDg 定义与 RAR4 目录的只读预览。
- `src/effect-preview.cjs`：EFF 层与关键帧的只读结构预览。
- `extensions/pkg-studio`：保留的 VS Code 插件；其 `runtime/` 由打包生成，不手工修改。

格式实现参考客户端读取逻辑及服务端表加载计划。不加载官方 GameAssembly，不连接官方服务器，不把素材包纳入 Git。
